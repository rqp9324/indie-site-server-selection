## 为什么独立站跑到一定阶段就得从虚拟主机搬走

虚拟主机的问题不是"便宜所以慢"，是资源模型决定的。几百个站点共用一台机器的 CPU 和 IO，你的 WordPress 装到第十个插件、数据库涨到几百兆，后台发篇文章都要转圈。

行业测试给出的差距很具体：共享主机平均 TTFB 在 800–1500ms，VPS 平均 100–300ms。Google 的公开数据是页面加载每多 1 秒，转化率下降约 7%。而对做独立站的人来说，TTFB 差的这 700ms 到 1.2 秒，落在结账页上就是真实的弃单。WordPress 目前占全球网站 43% 以上，绝大多数独立站跑的都是它，生态成熟的同时也意味着它对 IO 和内存格外敏感。

VPS 给的是独享 CPU 和内存、可以自己装 Redis 和缓存插件、可以挂 CDN、可以在一台机器上放几个站点、可以跑 WooCommerce 的完整订单流程。这些能力虚拟主机给不了，不是因为商家小气，是架构上就不允许。

## 第一步永远是定节点，不是定配置

节点选错，后面所有优化都是白费。三个主流方向的实际差别：

**香港**：核心价值是免 ICP 备案，下单即用，国内访问延迟低。第三方测评汇总的数据是华南 40–50ms、华东 60–70ms、全国平均 60–70ms，三网回程基本直连（部分商家会宣传"华南 20–40ms"，这个数字偏乐观，按第三方口径理解更稳）。短板是带宽贵：香港带宽成本高于内地，同价位下带宽普遍偏小，30Mbps 就算不错了。

**美国**：带宽白菜价。美国独立服务器 100M 不限流量 + 5 个 IP 的配置，月付 99 美元起，这个带宽量级在香港要贵出一个数量级。代价是国内访问延迟高、晚高峰容易抖。客户在欧美，美国节点是唯一正确选择。

**新加坡**：覆盖东南亚本地用户最合适，新加坡到东南亚各地 20–60ms。但它不是为中国大陆优化的线路，LisaHost 自己的页面写得很直白：非大陆直连优化网络，建议通过香港或日本线路中转使用，香港中转延迟约 30ms、日本约 70ms。你人在国内要频繁登后台，就得接受多一跳。

一句话：**访客在哪，机器在哪；你在哪，只影响你运维舒不舒服。**

## 线路名词翻译：9929、4837、CMI、iCable 到底差在哪

搜独立站服务器租用的时候，最容易懵的就是这一堆数字。它们其实是运营商骨干网的编号和机房接入方式：

- **9929**：联通 AS9929，回国质量优先级高，晚高峰相对稳，价格也高。LisaHost 美国 9929 系列就是这个定位，1核1G 卖 68元/月。
- **4837**：联通 AS4837，带宽给得大方、成本低，适合跑大流量。同一家 1核1G/20G NVMe/3TB/300Mbps 也是 68元/月，2核2G 直接给到 500Mbps 和 8TB 只收 100元/月。要带宽不要极致回国质量，选它。
- **CMI**：中国移动国际，香港方向常见的接入方式，三网访问表现均衡，免备案场景的主力。
- **iCable**：香港本地运营商有线宽频，特点是能给双 ISP 住宅 IP，适合需要港区本土 IP 属性的业务，比如港区流媒体、本地化运营。
- **BGP / 精品 BGP / 国际 BGP / CN2 GIA**：这是行业通用的线路分级。优质 BGP 三网择优、延迟 50–80ms、性价比最高；精品 BGP 或 CN2 类延迟更低更稳，但带宽常从 15Mbps 起、价格更贵；国际 BGP 国内延迟高、海外和东南亚表现好，适合纯跨境独立站；CN2 GIA 国内最好，成本也最高。

买之前先问自己一句：**我的访客从哪条线进来？** 面向欧美客户却买了回国优化线路，等于花钱买了个自己用不上的功能。

## 配置对照：1核1G 能干什么，2核2G 到哪一步就不够了

把配置和场景对上，比看跑分有用。

- **1核1G**：单站点、纯展示型官网、日 PV 几百到一两千的博客。WordPress + MySQL 能跑，但别装 Redis，也别指望后台同时开三个插件在跑。
- **2核2G**：这是跑 WooCommerce 的实际起点。WordPress + MySQL + Redis 建议至少 2GB 内存起步，2核2G 能撑住几十到一两百个 SKU、装了缓存插件、日均几千 PV 的常规电商站。
- **4核4G 及以上**：多站点运营、SKU 上千、大促期间并发下单、或者同一台机器上还要跑采集/API 服务。

硬盘这块，NVMe 比传统 SSD 快 3–5 倍，对数据库读取的提升是能感觉到的。LisaHost 全系标的都是 NVMe，这点不用纠结。

带宽要单独说清楚，因为这里有个特别容易踩的坑：**"5Mbps 独享带宽"和"300Mbps 端口 + 6TB 月流量"不是一回事。** 前者是持续保障的速率，后者是端口上限加月度总量，跑满了要么限速要么停机。行业建议电商独立站配 5Mbps 以上带宽，说的是前一种；而大部分海外 VPS 卖的是后一种。看套餐时先看月流量够不够你的实际消耗，再看端口数字。

## FAQ

**独立站服务器租用需要备案吗？**
服务器放在中国大陆以外（香港、美国、新加坡等）不需要 ICP 备案，开通即用。但如果用国内 CDN 加速、或者域名要走国内解析服务，那是另一套合规要求，和服务器位置无关。

**2核2G 够跑 WooCommerce 吗？**
常规规模够。WordPress + MySQL + Redis 建议至少 2GB 内存起步，2核2G 能支撑几十到一两百个 SKU、装了缓存插件的站点。商品上千、插件装到二三十个，就该上 4核4G。

**年付还是月付？**
年付便宜是真的。以新加坡特价年付版为例，466元/年折合 38.8元/月，同样的 1核1G 配置月付是 68元，一年 816元，年付省 350元，约 43%。但年付把风险和商家绑定了 12 个月，新商家建议先月付跑一个月，确认稳定性再转年付。

**香港和美国到底怎么选？**
看访客来源占比。访客七成以上在欧美，选美国，带宽便宜、延迟对目标用户最低；访客以亚太为主，或者你自己每天要在后台操作，选香港，60–70ms 的体感差别很明显。

**LisaHost 的套餐能装宝塔吗？**
Linux 环境可以，KVM 架构、有 root 权限，宝塔、1Panel、LNMP 都能装。装之前先把系统盘空间算好，10GB 硬盘的入门款装完面板和 WordPress 就所剩不多。

**48 小时退款怎么用最划算？**
收到机器先测三件事：从你常用网络 ping 和 traceroute 看延迟与回程、用 fio 或 dd 压一下硬盘 IO、装好完整环境跑一遍首页加载。三项都过再开始迁站，任何一项不达标就在窗口内提工单退掉。
